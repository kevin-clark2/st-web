JavaScript Skill Definitions

  • none - I don't know JavaScript.
  • read a book - I have read a book and seen JavaScript on web pages.
  • novice - I know the basic JavaScripts but use an editor to create pages.
  • skilled - I have designed pages on my own using Javascript.
  • very skilled - I have implemented commercial projects using JavaScript.
  • guru -  I have created commercial web pages with JavaScript and know how to debug Javascript
